# Gauss Solver
## Description 
This program takes a .csv file, solving a system by Gauss method and then writing the result on result.csv

## Requirements
* `C++ 20`
* `make`
* `gtest`
* `Eigen`

## Build 
``` Bash
make 
```
.. and one from available targets:
* `all`     -   Build the main ASCII85 encoder/decoder program
* `test`    -   Build and run unit tests
* `clean`   -   Remove all built files
